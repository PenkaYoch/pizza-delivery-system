# Pizza System

Pizza delivery demo with a task service, notification service, Kafka messaging, PostgreSQL, MongoDB, and a small browser UI.

## Services

| Service | Port | Description |
| --- | --- | --- |
| Frontend | `5173` | Kitchen console UI |
| Task service | `8080` | Creates and lists pizza tasks |
| Notification service | `8081` | Lists notification history |
| PostgreSQL | `5432` | Stores pizza tasks |
| MongoDB | `27017` | Stores notification logs |
| Kafka | `9092` | Carries pizza status events |

## Run With Docker

From the project folder:

```powershell
cd pizza-system
docker compose up -d --build
```

Open the frontend:

```text
http://localhost:5173
```

The frontend is served by Nginx and proxies API calls through the same origin:

```text
http://localhost:5173/api/tasks
http://localhost:5173/api/notifications
```

## API Endpoints

Task service:

```http
POST http://localhost:8080/api/tasks
GET  http://localhost:8080/api/tasks
GET  http://localhost:8080/api/tasks/{id}
```

Notification service:

```http
GET http://localhost:8081/api/notifications
```

Example task request:

```json
{
  "name": "Margherita"
}
```

## Frontend Development

The frontend is dependency-free HTML, CSS, and JavaScript.

If Node.js is installed, you can run the local static server:

```powershell
cd pizza-system/frontend
npm run dev
```

Then open:

```text
http://localhost:5173
```

If Node.js is not installed, use Docker:

```powershell
cd pizza-system
docker compose up -d frontend
```

## Useful Commands

Rebuild one service:

```powershell
docker compose build --no-cache task-service
docker compose up -d task-service
```

View logs:

```powershell
docker logs pizza-task-service --tail 100
docker logs pizza-notification-service --tail 100
docker logs pizza-frontend --tail 100
```

Stop everything:

```powershell
docker compose down
```

Stop and remove database volumes:

```powershell
docker compose down -v
```

## Troubleshooting

If the frontend opens but data does not load, check the backend endpoints directly:

```text
http://localhost:8080/api/tasks
http://localhost:8081/api/notifications
```

If those work but the UI still fails, rebuild the frontend so the Nginx proxy config is current:

```powershell
docker compose build --no-cache frontend
docker compose up -d frontend
```

If a container is not running:

```powershell
docker ps -a
docker logs <container-name> --tail 100
```
